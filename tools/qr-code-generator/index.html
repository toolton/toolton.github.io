Free QR Code Generator Online

Toolton's free QR Code Generator lets you create a QR code from a website URL, text, email address, phone number and other text-based information. The generated QR code can be downloaded as a PNG image.

How to create a QR code

Enter your URL or text in the box above, choose the QR code size and margin, and select Generate QR Code. Once your QR code appears, select Download PNG to save it.

What can you put in a QR code?

Website URL

Create a QR code that opens a website, landing page or online resource.

Plain text

Turn a short message, note or other text into a scannable QR code.

Email address

Create a QR code containing an email address or email-related information.

Phone number

Create a QR code containing a phone number for easy scanning.

QR code for a website or URL

To make a QR code for a website, paste the complete URL into the text box. For example: https://example.com. After scanning the generated code with a phone, the device can use the encoded URL.

Is this QR Code Generator free?

Yes. Toolton's QR Code Generator is free to use and does not require an account.

Does Toolton store my QR code content?

No. QR generation happens in your browser. Your entered content is not sent to a Toolton server by this tool.
