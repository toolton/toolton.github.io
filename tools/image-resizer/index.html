Free Image Resizer Online

Toolton Image Resizer is a free online tool that lets you resize JPG, PNG and WebP images to exact dimensions. Resize photos in pixels, centimetres, millimetres or inches without installing software or creating an account.

Resize Photos to Exact Size

Enter the exact width and height you need and choose your preferred measurement unit. You can keep the original aspect ratio or unlock it when you need completely independent width and height values.

Passport Photo Resizer

Create commonly required passport-photo dimensions using the built-in presets. You can also enter a custom size when a particular application or organisation requires a different dimension.

Signature and Document Sizes

Resize signatures, document images and other photographs using preset or custom dimensions. DPI settings are available when you need to work with physical print dimensions.

Reduce Image File Size

Adjust image quality and optionally specify a target file size in KB or MB. This is useful for online forms and applications that limit the maximum image size.

Convert JPG, PNG and WebP

Resize your image and choose JPG, PNG or WebP as the output format. This allows you to resize and convert an image in one simple step.

No Login Required

Toolton Image Resizer is designed to be simple and accessible. You can use the tool without creating an account or signing in.

Privacy-Focused

Image processing is performed directly in your browser. Your selected image does not need to be uploaded to a Toolton server for resizing.

How to Resize an Image Online

  1. Choose an image or drag and drop it into the upload area.
  2. Select a preset or enter your own width and height.
  3. Choose pixels, centimetres, millimetres or inches.
  4. Set the DPI if required.
  5. Keep the aspect ratio locked or unlock it for independent dimensions.
  6. Choose the output format and image quality.
  7. Optionally enter a target file size.
  8. Click Resize & Download .

Frequently Asked Questions

Is Toolton Image Resizer free?

Yes. Toolton Image Resizer is free to use and does not require an account or login.

Can I resize an image to an exact width and height?

Yes. Enter the required width and height and select the appropriate measurement unit. You can also unlock the aspect ratio when the two dimensions need to be independent.

Can I resize an image in centimetres or inches?

Yes. The tool supports pixels, centimetres, millimetres and inches. DPI can be adjusted for physical-size requirements.

Can I create a passport-size photo?

Yes. Select one of the passport-photo presets or enter a custom dimension. Always verify the exact photo requirements of the organisation or application you are submitting to.

Can I resize a signature?

Yes. A signature preset is available, and you can also enter your own required dimensions.

Can I reduce an image to a specific KB?

You can enter a target file size in KB or MB. For JPG and WebP images, the tool can adjust compression to get as close as practical to the requested size.

Does Toolton upload my image?

The resizing process is designed to run directly in your browser. Your selected image does not need to be uploaded to a Toolton server for the resizing process.

Which image formats are supported?

You can upload JPG, PNG and WebP images and choose JPG, PNG or WebP as the output format.

Can I use the Image Resizer on my phone?

Yes. The tool is designed to work in modern mobile, tablet and desktop browsers.
